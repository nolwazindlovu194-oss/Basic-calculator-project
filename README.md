Basic Calculator

  About
A simple console-based calculator created using C++

  What it does
- Addition
- Subtraction
- Multiplication
- Division
- to the power of...
- if the user inputs a division by zero, an error message will appear

  Applications and Software:
- Microsoft Visual Studio
- C++

  What I learned
I learned how to use Switch in a way I haven't used it before (I would use it for user
selecting options, not in the way of telling what the program it should do.), I finally
also understood how to use #include <cmath> 

  How to Run

1. Clone or download the repository.
2. Open the project in Microsoft Visual Studio.
3. Build the solution.
4. Run the program.
